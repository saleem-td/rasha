# رشا صالح — Portfolio

موقع شخصي احترافي ثابت (Static Website) باللغة العربية، جاهز للنشر على GitHub Pages.

## التشغيل محليًا
افتح `index.html` مباشرة في المتصفح، أو استخدم Live Server في VS Code.

## النشر على GitHub Pages
1. أنشئ Repository جديدًا على GitHub.
2. ارفع الملفات الموجودة في هذا المجلد.
3. من **Settings → Pages** اختر **Deploy from a branch**.
4. اختر `main` ثم `/ (root)` واضغط Save.
5. بعد دقائق سيظهر الموقع على رابط GitHub Pages الخاص بالمستودع.

## إضافة صورة شخصية
ضع صورتك داخل `assets/profile.jpg`، ثم استبدل عنصر `.portrait-placeholder` في `index.html` بعنصر `<img>` إذا رغبت.
